# DRACU-RIOT! 阅读器

把小米手环同人移植版《DRACU-RIOT!》整套搬上 AI Passport 的竖屏视觉小说阅读器：五条女主线、
各自的后日谈与结局，全程离线，三个按键操作。它是本 fork 在 ATRI / 千恋万花阅读器页面体系上
做的第四个应用，数据层则是为「源工程是线性页表」这类作品新写的。

## 发布信息

- **标题**：`DRACU-RIOT! GalGame`（简体中文与英文相同）。
- **说明**：把《DRACU-RIOT!》手环移植版搬到 AI Passport：一台完全离线的竖屏视觉小说阅读器。
  整部作品的五条女主线、各自的后日谈与结局都装在设备里，开机就能从序幕一路读到结局。
  剧情引子：漂浮在海上巨大人工岛屿海上都市，是个赌博和风俗合法发展的特区；主角六连佑斗受
  好友邀请来到这座城市，途中被卷入绑架事件，并因此变成了吸血鬼，只能在这座政府唯一认可
  吸血鬼与人类共同生活的城市里生活下去。体量：52,787 页剧本、约 113.8 万字、54 处选项、
  62 个章节节点、244 张事件 CG、85 张背景，全部离线。
- **来源**：`https://github.com/Shinku-Chen/ai-passport/tree/feature/dracu-riot`
- **封面**：`dracu-riot-cover.png`，PNG，480 × 640（3:4），五位女主的主视觉。这里只登记文件名
  与格式，封面本体不入库。

## 它做什么

- **开机即标题页**：开始阅读就从序幕一路读到结局，不在中途切出去；章节列表是独立的辅助入口，
  不是"开新游戏"的入口。
- **五条线五个结局**：选择历史驱动路线分叉，每条线各有自己的章节、专属结局与后日谈；
  "章节跳转"覆盖全部 62 个章节节点（含后日谈）。
- **阅读操作**：上/下短按推进一句（正在逐字显示时按一下先补全整句，长句自动分页），长按上快进、
  松手即停，长按下开关自动阅读，确定打开菜单。
- **存档**：1 个自动存档（换章、做选择、睡前写入）+ 5 个手动存档；标题页的"继续阅读"接自动存档。
- **空闲策略**：60 秒调暗、3 分钟熄屏、7 分钟休眠，任意键唤醒；自动阅读与快进期间不算空闲，
  应用自己在推进剧情时屏幕不熄。
- **完全离线**：不联网、不配网、不需要账号，剧本与美术都在固件内的数据包里。

## 交互与流程

三个按键：上 / 下 / 确定。

- **标题页**：上/下移动光标、确定进入。菜单：开始阅读 / 继续阅读 / 读取进度 / 章节跳转 / 系统设置。
- **正文**：如上；确定打开菜单（继续阅读、保存进度、读取进度、跳过章节、返回标题）。
- **选项**：上/下选择、确定确认，选完立刻存档。
- **章节跳转**：上/下在 62 个条目里移动、确定跳转、长按确定返回。
- **存档页**：短按确定存/读，长按确定删除该档。
- **结局**：每条线各自播结局页；读完后清掉自动存档，避免"继续阅读"指向已经走完的进度。
