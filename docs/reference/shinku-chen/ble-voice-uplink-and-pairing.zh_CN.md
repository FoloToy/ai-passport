# 让手机做网络、设备只做 BLE 语音上行

这些结论来自 **Pocket Intercom（随身 AI 对讲机）** 手机链路在真机上的验证（2026-10-01）。属于通用、对上游也有价值的经验：任何想让语音经由手机离开设备、而不是让设备自己上网的 AI Passport 应用都用得上。

> **验证状态。** 在一台 AI Passport 真机 + 一部安卓手机上实测：配对、完整一轮对话（走了两种不同网关）、按下响应速度与下面的上行速率都取自设备或手机日志，不是估算。距离、续航、多部手机同时连接、长时间会话**未覆盖**。

## 为什么把网络交给手机

这块板子没有 PSRAM，可用堆只有几十到几百 KB；而手机本来就拿着凭据、语音识别会话和网关连接。让设备做纯 BLE 外设意味着：

- 设备端**完全不需要** Wi-Fi 配网流程，也就没有了"三个键怎么输密码"这个难题；
- 网关 token / API key 只有手机一份，**从不下发到设备**，所以设备镜像泄露也不会连带泄露凭据；
- 固件里不必出现 HTTP 解析、TLS、JSON 处理以及随之而来的各种缓冲区尺寸取舍。

代价是设备离开手机就没法用，且手机进入延迟链。对手持对讲机可以接受；对独立播放器不可接受。

## 链路形态

- 传输采用 Nordic UART Service 布局（`6e400001`/`6e400002`/`6e400003-b5a3-f393-e0a9-e50e24dcca9e`），这样通用 BLE 工具和任何手机协议栈都能直接接入，不用自己搓 UUID。
- 帧格式为 `[A5 5A][TYPE][FLAGS][LEN:2 大端][payload]`，并带 magic 重同步规则：一次截断的写入不会让接收端永久失步。一次通知里可能来多帧，一帧也可能被拆进多次通知，所以解析器基于环形缓冲工作，并跨写入保留半帧。
- 设备做外设、手机做中心。角色固定，就省掉了对称联机所需的那套"谁先连"的仲裁逻辑。
- 链路上对上行音频帧做**限流**，而不是让编码器产出多少就发多少；否则手机端一快就会把传输层饿死，表现为延迟尖刺而不是平缓降级。

## 配对

- LE Secure Connections + MITM，并且 bonding；配对码是设备生成并显示在屏幕上的 **6 位数字**。这个值必须 ≥ `100000`：更小的值在 Android 侧会被直接拒掉。
- bonding 会落盘，所以每部手机只需配对一次。每次新的配对尝试都会重新生成配对码；"配对成功却立刻掉线"最常见的原因就是手机上残留的旧 bond。
- 配对发生在任何凭据存储之前，因此刚出厂、刚刷机的设备上不存在密钥。没有"手机应用往设备写一个 key"的配网步骤；网关可能需要的设备身份在手机侧生成并保存。

## 音频上行：在没有 PSRAM 的芯片上跑 Opus

- Opus，16 kHz 单声道、60 ms 帧（960 采样）、complexity 0、开 DTX。帧长约 180 字节，上行约 **3 KB/s** —— 大约是 16 kHz 裸 PCM 的十分之一，链路吞吐因此离上限还很远。
- complexity 0 是刻意的：在这类芯片上更高的档位会把 LVGL 与链路任务也要用的核心吃满。
- 编码跑在**静态栈**任务上（这里是 24 KB）。每次录音都临时申请编码栈会把无 PSRAM 的堆打碎；改成单个常驻任务 + 静态栈后，这一类故障彻底消失。
- 协议里保留裸 PCM 帧类型作为回退路径，出现链路或编码问题时可以在不改帧格式的前提下做隔离。

## 响应感：按下即红、就绪才绿

- 屏幕反应由**按下事件**驱动，与网络状态无关：按键一按下整屏立刻变红，用来告诉用户"设备已经在听你说话"。
- 绿色表示"网关就绪，可以开口说"，由手机在识别通道可用时下发。参考手机上实测按下到变绿约 **280–290 ms**。
- 因为这个反应依赖手机，所以必须有**兜底**：如果"就绪"通知一直不来，界面要能自己回到可用状态，而不是永远停在红色。一个很短的超时（本应用取 800 ms）就够覆盖正常情况，并避免手机休眠或超出范围时屏幕卡死。
- 手机侧换来这个数字的办法是让识别通道**常驻预热**：保持会话 + 心跳保活、定期复检，按下时就不用为建连接付费。

## 可以照抄的与要留神的

- 照抄：固定的外设/中心角色划分、NUS UUID、带 magic 重同步的长度前缀帧、音频限流、编码用静态栈、协议级 PCM 回退、由按下事件驱动的视觉反馈 + 兜底超时。
- 留神：把链路当成 socket 用（它其实是通知流，通知长度不固定）、让设备去做中心（要多付仲裁逻辑的代价，扫描还会和手机抢信道）、以及让"就绪"状态依赖用户看不到的东西 —— 兜底超时正是让这件事保持诚实的关键。
