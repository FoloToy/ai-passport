# 无人值守的自动推进：从文字结束开始计时，并把它算作活动

在发布 **亚托莉阅读器** 之后整理：长按上键启动的模式会在没有任何后续输入的情况下自己往下读。

## 从打字机结束开始计时，而不是从这一行开始

第一版在文字"显示完"的瞬间就翻页，只留 250ms 下限防止"瞬间"文字速度连翻。真机上看起来是
一片糊：等视线读完两行句子，这一行已经过去了。

最终发布的版本是**打字机结束后固定等 700ms** 再翻。两个细节让它成立：

- 打字机还在跑的时候，把倒计时**钉在满格**，而不是让它流逝 —— 这样"一句话读完后停多久"
  与该句出现耗时无关。
- 停顿与文字速度设置**互相独立**：速度设置决定一句话怎么出现，停顿决定它停留多久供人阅读。

## 停止条件与连续性

- 遇到选项与结局停下 —— 那需要玩家决策。
- 换幕、换章的过场**不中断**：章节之间的淡出淡入不是"停止点"，在那里取消模式会逼用户每章
  重新开一次。
- 任何真实按键立刻交回控制权；而模式开关本身不能被它自己的抬起事件取消（见三键输入那条）。
- 模式**不跨重启保留**：开机就自己往下翻的设备会让人困惑。
- 在屏幕上显示这个模式。角落里一个小标记就够了 —— 一个不经输入就改变行为的模式，必须能被
  发现。

## 与空闲计时的相互作用

自动推进属于"活动"，所以它不能给调暗 / 熄屏 / 深睡的计时器喂数据：按默认的 45 秒调暗、
150 秒熄屏，长时间无人看管会在读到一半时黑屏。但停在某个决策点等玩家属于"空闲"，所以这条
豁免的条件是"模式开启 **且** 正在推进"。

实测表现：改完之后，无人值守的自动阅读全程保持点亮；模式关掉后空闲计时从头开始，任何等待
输入的界面依旧会正常调暗、熄屏与深睡。
