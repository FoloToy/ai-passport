# 星空列车与白的旅行

把商业作品《星空鉄道とシロの旅》的手环同人移植版（小米手环 9 Pro 快应用）连同其中文译文
移植到 AI Passport 的竖屏视觉小说阅读器。整条剧情离线跑在 Flash 里：**39 章、1,260 个
场景、13,787 句对白、一处选项、一个结局**，不需要往设备里拷任何文件。

## 发布信息

- **标题**：星空列车与白的旅行 / Starry Sky Railroad and Shiro's Journey
- **简介**：把 AI Passport 变成一台口袋视觉小说机：开机就是标题页，从第一句一直读到唯一的
  结局。39 章、13,787 句对白的正文全部存放在机身上 —— 不需要联网，也不需要往设备里拷任何
  文件。乘坐的列车划破夜空，飞驰在星空之下；舒爽夜风吹拂下的随心独旅中，我邂逅了随性的
  乘客、惹人怜爱的乘务员，以及……猫耳少女？剧情推进到中途会出现一处选择，最终走向唯一的
  结局。只有正在说话的角色才会出现在画面上，旁白与事件插画上不会贴一张脸；每次换场景都会
  自动存档，随时合上、随时接着读。
- **分类**：games

  <https://github.com/Shinku-Chen/ai-passport/tree/feature/starry-sky-railroad>
- **封面**：`starry-sky-railroad-cover.png`，PNG，1152 × 1536（精确 3:4）。档案馆只存文本，
  图片本身不在这里。

## 它做什么

- **开机直接进阅读器**：标题页提供开始阅读、继续阅读（自动存档）、手动存档位与系统设置。
  没有 demo 菜单，也不依赖网络。
- **界面沿用 ATRI 阅读器的 LVGL 页面系统**：标题页、带打字机效果的正文、选项、游戏内菜单、
  设置、5 个手动存档位 + 1 个自动存档位、章节过场卡、结局卡与关于页。
- **立绘只在该角色本人说话时出现**：归属关系由打包器按"哪个有名字的说话人引用了这张立绘"
  统计得出；旁白与他人说话时收起，事件插画与纯色幕上永远不会贴一张脸。全剧本 11,777 个
  对白步里有 3,444 步会画出立绘。
- **松手即停的快进**；自动阅读在每句显示完整后约 0.9 秒翻页（按其它键停止）。
- **随时接着读**：每次换场景自动存档。放着不管 60 秒调暗、3 分钟熄屏、7 分钟休眠，
  任意键唤醒后继续读。

## 布局

```text
┌────────────────────────────┐  240 x 320,竖屏握持
│ 第8章            [电量]    │  左上角章节纯文字,右上角电量纯文字
│  画面区                    │  一张整屏 240 x 320 背景 JPEG,角色立绘压在上面,
│  240 x 320                 │  角色名带半透明底板(名牌在正文带左侧,不遮正文)
│  诺瓦                      │
├────────────────────────────┤
│  正文                      │  半透明蓝色正文带压住画面下沿,高 110px
│                            │  16px 字号:每行 13 个全角字,5 行
└────────────────────────────┘
```

底部 110px 是半透明蓝色正文带，立绘压在**带子下面** —— 与源移植版一致，人物下半身落进
正文带里，带子以上的部分不受影响；文字那几行再盖一层淡暗帘，白字在任何画面上都能读。

## 交互

| 按键 | 阅读正文时 | 列表页 |
| --- | --- | --- |
| 上 / 下（短按） | 下一句（打字中按一下先显示全文） | 移动光标 |
| 上（长按） | 按住期间快进，松手立刻停 | — |
| 下（长按） | 自动阅读开关（每页约 0.9 秒） | — |
| 确定（短按） | 菜单：继续 / 保存 / 读取 / 跳过章节 / 返回标题 | 选中 |
| 确定（长按） | — | 返回 |

菜单里的「跳过章节」跳到下一章开头并播放章节过场卡；已经是最后一章时会提示已到结尾。
存档页里长按确定可删除该存档位。

## 已知缺口

- 源数据缺第 7 章（章节文件从 6 直接跳到 8），源应用的分支标记也从未被设置，所以剧情是
  1 → 40 直达唯一的 `FIN` 结局。本移植忠实保留源数据的现状。
- 本作只有一个结局、也没有按结局解锁的标记，因此标题菜单里没有"真正的结局"入口。
- 拉丁字母按源字体的自然宽度排，而排版模型按半角格子预算，所以夹着较长英文单词的行最多会
  超出正文区一个全角字（全剧本 19,986 行里 2 行）；LVGL 标签会在自己的盒子内换行。
- 无音频：源移植版没有音频，这里也不加。
- 尚未在硬件上把整条剧情从头玩到尾；单章阅读、翻页、立绘与正文带的叠压顺序、跳过章节流程
  以及真机截图钩子都已在实机上核对过。
