# ATRI Reader

A portrait visual-novel reader for the AI Passport: the complete *ATRI -My Dear
Moments-* story in 34 chapters, 1,069 scenes, 12,188 dialogue lines and three
endings, read entirely offline with the device's three buttons. The script,
backgrounds, full-body character sprites and the Chinese font subset are all built
into one merged firmware image.

## What it does

- **Boots straight into the reader**: the firmware opens the visual novel's own
  first-run notice and title screen, with no test menu and no network use.
- **Full offline story**: a 3.8 MB resource pack carries 12,188 dialogue lines,
  73 full-screen backgrounds, 14 effect overlays and 5 full-body character sprites;
  a 16 px Chinese font subset of about 2,770 code points (about 0.39 MB of flash)
  covers every UI string and every script character. Both are generated by tools in
  this repository and committed, so a plain checkout builds.
- **Speaker-driven sprites**: a sprite appears only on a line that carries a speaker
  name and hides as soon as that character stops talking. Event CGs (`ev*`), black
  screens (`none*`) and the masked variants (`mask*`, `hurt*`) never show one, the
  viewpoint character never appears, and the alternate spellings the script uses for
  the same character (robot girl, the girl, three spellings of Ririka, the voice
  lines) all resolve to the same sprite. Sprites stand 6 px from the right edge of
  the art area.
- **Portrait layout**: a 240 × 320 art area with the source's translucent blue text
  band alpha-blended into the canvas, a speaker name plate, the chapter number in
  the top-left corner, the page counter in the bottom-right corner, and a light scrim
  over the text rows so a sprite is never hidden behind the dialogue box. Backgrounds
  stay JPEG; sprites and overlays use lossless RGB565 colour plus a 4 bpp alpha mask,
  which keeps a full-screen composite affordable on a part without PSRAM.
- **Reading modes**: typewriter text at four speeds (instant / slow / medium / fast),
  fast-forward that renders whole lines until the key is released, and auto-read
  where a line advances 700 ms after it finishes typing.
- **Saves**: five manual slots plus one automatic slot written on every scene
  change, offered as "continue" from the title screen. The v2 save format keeps the
  current sprite and still reads v1 saves.
- **Endings**: the script's three decisions lead to the happy or the bad ending;
  seeing both unlocks the true-ending chapter on the title screen, which is how the
  source Mi Band port gates its extra episode.
- **Idle behaviour**: 45 s dims the backlight, 2.5 minutes turns the screen off and
  7 minutes enters deep sleep, with any key waking the device back to the title
  screen. Auto-read is not idle time, so an unattended run keeps the screen awake;
  waiting on a choice or an ending is not activity and still turns the screen off.
- **Verification aids for later iterations**: the USB serial console accepts
  `ATRIJUMP <chapter> [scene]` (moves the live reading position) and
  `ATRISHOT <chapter> <scene>` (renders that scene into the canvas and streams the
  raw 240 × 320 frame back), and `idf.py -DATRI_BOOT_CHAPTER=<index> build` boots
  straight into a chapter.

## Interaction

Three keys drive the whole app; the battery readout sits in the corner of the art
area.

The screens are: first-run notice, title, reading, menu, save/load list, settings,
about, and the ending card.

Title screen and lists:

- **UP / DOWN**: move the cursor.
- **OK**: enter the selected item (start, continue, unlockable true ending, load,
  settings).
- **OK (hold)**: go back one level.

While reading:

- **UP / DOWN (short)**: advance one line.
- **UP (hold)**: fast-forward through whole lines until released.
- **DOWN (hold)**: start or stop auto-read; a marker appears in the bottom-right
  corner while it runs and any real key press hands control back.
- **OK (short)**: open the menu - continue, save, load, skip chapter, back to title.
  Skipping a chapter runs to the next chapter and stops at any choice or ending.
- At a choice: **UP / DOWN** selects and **OK** confirms.

Save screens: **OK** overwrites the selected manual slot or loads it, and
**OK (hold)** deletes a manual slot.

Press timing: a press shorter than 120 ms is ignored, and holding a key for 300 ms
triggers the long-press action.
