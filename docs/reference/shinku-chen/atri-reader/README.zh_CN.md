# 亚托莉阅读器

AI Passport 上的竖屏视觉小说阅读器：完整《亚托莉 -My Dear Moments-》剧情，34 章、
1,069 幕、12,188 句对白、3 个结局，只用设备上的三个按键就能全程离线读完。剧本、背景、
全身立绘与中文字体子集都编进同一份合并镜像。

## 它能做什么

- **开机即进阅读器**：固件直接打开阅读器自己的首次提示与标题页，没有测试菜单，也不使用网络。
- **完整离线剧情**：3.8 MB 资源包内含 12,188 句对白、73 张全屏背景、14 张特效叠加与 5 张
  全身立绘；16px 中文字体子集约 2,770 个码位（约 0.39 MB Flash），覆盖全部界面文案与剧本用字。
  两者都由本仓库内的工具生成并提交，普通 checkout 即可构建。
- **立绘跟说话人**：只有带人物名称的台词才出现立绘，该角色一说完就收起。事件 CG（`ev*`）、
  黑屏（`none*`）以及带遮罩的变体（`mask*`、`hurt*`）整幕都不叠立绘；男主的视角不出镜；
  剧本里同一角色的多种写法（机器人少女、少女、凛凛花的三种写法、声音台词等）都映射到同一张立绘。
  立绘站在画面区右侧、距屏幕边缘 6px。
- **竖屏版面**：240 × 320 画面区，源素材的蓝色半透明文字带以 alpha 混进画布，另有说话人名牌、
  左上角章节号、右下角页码，以及文字区上方的浅暗帘，保证立绘不会被对白框挡住。背景保持 JPEG；
  立绘与叠加使用无损 RGB565 颜色 + 4bpp alpha 遮罩，使无 PSRAM 的板子也能承受整屏合成。
- **阅读模式**：打字机文字四档速度（瞬间 / 慢 / 中 / 快）、按住上键整句快进直到松手、
  以及打字结束后停 700ms 自动翻页的自动阅读。
- **存档**：5 个手动槽 + 1 个自动槽（每次换幕自动写入，标题页的「继续阅读」读它）。
  v2 存档格式保留当前立绘，同时仍能读取 v1 存档。
- **结局**：剧本里的三次选择通向圆满或悲剧结局；两者都看到后，标题页解锁「真正的结局」章节，
  与源移植项目解锁追加章节的门槛一致。
- **空闲行为**：45 秒调暗背光、2.5 分钟熄屏、7 分钟进入深睡，任意键唤醒并回到标题页。
  自动阅读不计入空闲，无人值守时屏幕保持点亮；停在选项或结局上属于等待玩家，照常按时限熄灭。
- **便于后续迭代的验证手段**：USB 串口控制台支持 `ATRIJUMP <章> [幕]`（移动实际阅读位置）与
  `ATRISHOT <章> <幕>`（把该幕渲染进画布并回传原始 240 × 320 帧），
  `idf.py -DATRI_BOOT_CHAPTER=<序号> build` 可直接开机进入指定章节。

## 交互方式

三个按键贯穿全部界面；电量读数位于画面区角落。界面共有：首次提示、标题页、正文、菜单、
存档 / 读档列表、设置、关于、结局卡。

标题页与列表页：

- **上 / 下**：移动光标。
- **确定**：进入所选项（开始阅读 / 继续阅读 / 解锁后的「真正的结局」/ 读取存档 / 设置）。
- **长按确定**：返回上一层。

阅读正文时：

- **上 / 下（短按）**：下一句。
- **上（长按）**：整句快进，松手即停。
- **下（长按）**：开关自动阅读；开启时右下角显示标记，任何真实按键立刻交回控制权。
- **确定（短按）**：打开菜单 —— 继续阅读 / 保存进度 / 读取存档 / 跳过章节 / 返回标题。
  跳过章节会一直推进到下一章，路上遇到选项或结局就停下。
- 遇到选项：**上 / 下**选择，**确定**确认。

存档页：**确定**覆盖所选手动槽或读取它，**长按确定**删除手动槽。

按键时序：短于 120ms 的按下会被忽略，按住 300ms 触发长按动作。
