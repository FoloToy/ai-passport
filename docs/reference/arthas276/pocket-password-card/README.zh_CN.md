# 口袋密码卡

一张离线的派生密码卡：设备上只保存一张由 128-bit 种子派生的固定 8 × 10 字符网格，每个站点只是网格上的一个位置。不存任何密码、不联网，同一种子就能在任意一台设备上复现同一张卡。

## 功能

- **一张卡，派生而非存储**：首启用 `esp_fill_random` 生成 128-bit 种子，`xoshiro128**` 把它展开成 55 字符去混淆字母表（去掉 0/O/o、1/l/I/i）上的固定 8 × 10 网格。种子只存于单个 NVS blob，永不离开设备。
- **站点 = 行 + 列 + 长度 + 模式**（13 字节）：密码就是 80 格流上从该位置起的连续若干格，越过末尾回绕。普通密码 4-16 位。
- **PIN 模式**（v1.2）：4-6 位纯数字，来自同一种子 + 站点位置 + 「PIN1」域标记钥匙的独立流——任意设备可重建，但永不印在卡上，钱包卡被偷被拍也泄不出银行 PIN。
- **默认遮蔽**：OK 显示 8 秒并配缩短的倒计时条，到时自动遮回；任何其他键立即遮蔽。
- **站点管理**（v1.2）：密码屏长按上键经双确认删除该站；长按下键重开预填好的向导就地编辑。两个手势都写在屏上提示行里。
- **免电脑迁移**（v1.2）：种子页显示 32 位十六进制与 CRC-8 校验码；设置里用 0-9 a-f 打字轮直接录入种子，未满显示 n/32、满 32 位显示待确认种子的 CRC——抄错一位表现为校验对不上，而不是静默变成另一张合法卡。
- **存储 v2 自动迁移 v1.0**：440 字节 blob（每站多一个模式字节）读取时用一步纯函数（主机测试覆盖）转换 408 字节的 v1.0 blob 并自愈回写；v1.0 密码逐位不变。
- **闲置策略**：12 秒背光调暗、60 秒深睡，GPIO 按键唤醒并遵循仓库 key_guard 防误触契约。

## 交互

仅三键：UP/DOWN 移动与加速（长按连发），OK 确认；长按 OK 在每屏语义一致地返回。九个屏幕：卡网格（列头 A-J、行号 1-8、游标行高亮）、站点列表（尾固定添加行）、密码屏（遮蔽/显示）、五步添加/编辑向导（模式、行、列、长度、名称打字轮）、设置（重生成卡、查看种子、恢复种子、清空站点、玩法说明）、四路确认、种子页、种子录入页、首启帮助页。每屏页脚都写明当前手势。
