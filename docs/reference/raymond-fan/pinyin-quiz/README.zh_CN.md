# 拼音易错题

只围绕"初学者反复出错的那几个音"做的拼音练习。6 类考点、48 道题，答错自动进错题本，
每题答完给一句点名错因的解析，而不是简单判个对错。

## 发布信息

- **中文标题**：拼音易错题
- **社区项目**：`community-96e759d7`（project 2158，revision 5187），2026-11-10 提交，状态为待审核。
- **封面**：`pinyin-cover.png`——PNG，1152×1536，3:4。此处仅记录发布元数据；图片本身随社区发布保存，
  不存放在本目录。
- **简介**：这是给自家上小学一年级的孩子做的。孩子的拼音大部分还 hold 得住，但总有那么几个音
  反复错，而且错法很有共性——前后鼻音漏个 `g`、平翘舌混、`n` 和 `l` 不分、`ü` 上两点该去的没去、
  声调标错地方。于是把这些高频易错点单独整理出来，做成了这台随身练习机。48 道题分 6 类考点，
  每道题的干扰项都是真实会写错的答案。答错就进错题本，在错题本里答对一次就少一道，直到清空。
  三个键就能玩：上下选、确定答。

## 它做什么

- **只收易错点，不凑数**：48 道题分 6 类——`z/zh` 与 `c/ch`、前后鼻音、`n` 与 `l`、`ü` 省点规则、
  声调标调位置、形近字母（`b d p q f t`）。
- **干扰项都是真错法**：每个错误选项都复现学习者在这个词上真实会犯的错（漏 `g`、声母写反、
  标调标错位置），所以靠排除法猜不出来。
- **错题本存在 NVS**：任何模式答错都会按题记录。在错题本里答对一次，该题的错次减一；减到 0
  就移出。错次上限 9，复习顺序按错次从高到低，错得最多的先练。
- **给解析，不只给对错**：解析页显示词语、全屏最大字号的正确拼音，以及一条说明这个音错在哪的
  规则（例如 `péng` 带 `g`，`pén` 是"盆"）。
- **四个界面**：题型选择（全部混合、错题本、6 类考点）、答题、解析、结算（得分、正确率、星级）。
- **全程离线**：不需要联网、配对或任何设置。右上角显示电量，读不到时显示 `--`。

## 交互

- **上 / 下（短按）**：移动高亮。
- **确定（短按）**：进入题型、交卷、下一题、再来一轮。
- **确定（长按）**：从任意界面回到题型选择。

错题本是唯一的持久状态。它能在断电与固件更新后保留——这一点通过在已有错题数据的设备上
覆盖刷写新固件、再读启动日志验证过。

## 源码

- **公开源码**：`macwoos-crypto/ai-passport` 的 `app/pinyin-quiz` 分支
  （<https://github.com/macwoos-crypto/ai-passport/tree/app/pinyin-quiz>）。该分支在上游
  `FoloToy/ai-passport` 之上加入本应用；应用本身不在上游仓库内。同一地址已记录在社区项目上。
- 应用代码在 `main/`：`pinyin_quiz.*`（题库类型与纯 C 答题状态机）、`pinyin_quiz_data.c`（48 道题）、
  `wrong_book*.c`（错题本逻辑与其 NVS 层）、`app_pinyin.c`（界面与按键处理）。
- 字体：由 `tools/gen_app_fonts.py` 生成的 Noto Sans SC 子集。仓库自带的 Montserrat 既没有拼音调号
  （`ā á ǎ à`、`ǖ ǘ ǚ ǜ`），也没有汉字字形。生成器的字符清单从 `main/CMakeLists.txt` 实际编译的源文件
  推导，`--check` 会逐码位校验真实覆盖，而不是只看文件是否存在。Noto Sans SC 采用 SIL Open Font
