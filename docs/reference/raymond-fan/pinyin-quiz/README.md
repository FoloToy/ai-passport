# Tricky Pinyin

A pinyin drill built around the handful of sounds that beginner readers keep
getting wrong. 48 questions across six trouble categories, a review book that
tracks every miss, and a one-line explanation that names the actual trap instead
of just marking the answer wrong.

## Publish information

- **Title (English)**: Tricky Pinyin
- **Community project**: `community-96e759d7` (project 2158, revision 5187),
  submitted 2026-11-10, status pending review.
- **Cover**: `pinyin-cover.png` — PNG, 1152x1536, 3:4. Publish metadata only; the
  image itself lives with the community publication and is not stored here.
- **Description**: This was made for the author's first-grader. Most pinyin
  stuck, but a few sounds kept going wrong — and always in the same ways: a
  dropped `g` in the back-nasal finals, `z/zh` and `c/ch` mixed up, `n` and `l`
  swapped, the two dots on `ü` left on when they should go, tone marks in the
  wrong place. Those trouble spots were pulled out into a pocket practice
  machine. 48 questions across six categories, and every wrong option is a
  mistake learners really make. Miss one and it lands in the review book; get it
  right there once and it leaves, until the list is empty. Three buttons: up and
  down to choose, OK to answer.

## What it does

- **Only the traps, no filler**: 48 questions in six categories — `z/zh` and
  `c/ch`, front versus back nasals, `n` versus `l`, the `ü` spelling rule, tone
  placement, and look-alike letters (`b d p q f t`).
- **Distractors are real errors**: every wrong option reproduces a mistake a
  learner actually makes on that word (a missing `g`, a swapped initial, a
  misplaced tone mark), so guessing by elimination does not work.
- **Review book in NVS**: any wrong answer is recorded per question. A correct
  answer inside the review book lowers that question's count; at zero it leaves
  the book. The count is a level, capped at 9, and the review round is ordered
  by level so the worst offenders come first.
- **Explanation, not just a verdict**: the reveal page shows the word, the
  correct pinyin in the largest type on screen, and one rule that says where the
  sound goes wrong (for example, `péng` carries a `g`, `pén` is the character for
  basin).
- **Four screens**: category list (mixed round, review book, six categories),
  question, reveal, summary with score, accuracy and a star rating.
- **Fully offline**: no Wi-Fi, no pairing, no setup. Battery percentage in the
  top-right corner, `--` when the gauge cannot be read.

## Interaction

- **Up / Down (click)**: move the highlight.
- **OK (click)**: enter a category, answer, advance, or replay.
- **OK (long press)**: return to the category list from any screen.

The review book is the only persistent state. It survives power loss and firmware
updates, which was verified by flashing new builds over a populated book and
reading the boot log.

## Source

- **Public source**: `macwoos-crypto/ai-passport`, branch `app/pinyin-quiz`
  (<https://github.com/macwoos-crypto/ai-passport/tree/app/pinyin-quiz>). The branch
  carries the application on top of upstream `FoloToy/ai-passport`; the application
  itself is not part of upstream. The same URL is recorded on the community project.
- Application code lives in `main/`: `pinyin_quiz.*` (question bank types and a
  pure-C quiz state machine), `pinyin_quiz_data.c` (the 48 questions),
  `wrong_book*.c` (review-book logic and its NVS layer), and `app_pinyin.c`
  (screens and key handling).
- Fonts: a Noto Sans SC subset generated by `tools/gen_app_fonts.py`, because the
  bundled Montserrat fonts carry no pinyin tone marks (`ā á ǎ à`, `ǖ ǘ ǚ ǜ`) and
  no Chinese glyphs. The generator derives its inventory from the sources that
  `main/CMakeLists.txt` compiles and `--check` verifies real per-code-point
  coverage. Noto Sans SC is licensed under the SIL Open Font License 1.1.
