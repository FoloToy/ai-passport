# 贡献规范

本目录包含人类贡献者与 AI Agent 的完整文档和 Pull Request 规则。

## 文档

- [doc-conventions.zh_CN.md](doc-conventions.zh_CN.md)：双语结构、权威来源、放置位置、写作、安全和文件操作。
- [commit-and-pr.zh_CN.md](commit-and-pr.zh_CN.md)：Commit 格式、PR 证据、验证字段和审查范围。

每条规则都必须写明触发条件、必须动作、禁止动作和验证命令。产品与板级事实保留在 `docs/hardware-design/`。
