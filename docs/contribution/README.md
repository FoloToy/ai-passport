# 协作规范（Contribution）

本目录存放适用于任何项目的通用协作规范（公共文档，可提上游）。

## 收录标准

- 只收录通用协作规范（文档规范、commit 风格、PR 约定等），对任何项目成立。
- 每条规则应写清触发条件、必须做什么、禁止做什么、验证方法和例外条件。
- 本项目专属的功能/产品设计细节属特定项目文档，不提上游（见 [doc-conventions.md](doc-conventions.md)）。
- 可以由 lint、测试或脚本强制的要求，应同时落实到自动化检查，不能只靠 agent 阅读文字。
- 新增规约时在本文件更新索引。

## 文档索引

- [doc-conventions.md](doc-conventions.md)：先读根目录所有 README + 文档生成规范 + 文档分类规范（公共/特定项目）。
- [commit-and-pr.md](commit-and-pr.md)：提交规范 + 提交与 PR 约定。
