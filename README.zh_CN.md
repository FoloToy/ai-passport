# AI Passport · 老人安心牌

老人安心牌把 FoloToy AI Passport 变成一张离线随身求助卡。老人迷路或需要帮助时，
屏幕可以显示称呼、求助说明、家庭联系人、居住区域、健康提醒和家属微信二维码。

## 使用方法

1. 第一次启动时，扫描设备屏幕上的 Wi-Fi 二维码。
2. 手机连接受密码保护的设备本地热点，并打开设置页。
3. 填写安心资料，并可选择上传家属微信二维码。
4. 保存资料。设备会把资料写在本地，并立即关闭 Wi-Fi。
5. 用上、下键翻页；在微信页短按确认键显示二维码，按任意键返回。
6. 长按确认键可重新打开本地设置；若已经设置管理密码，设置页会要求验证。

正常展示时一分钟无操作会进入深度休眠；本地设置热点五分钟无操作会休眠；按任意功能键唤醒。

## 隐私与安全

- 资料只保存在设备 NVS 分区，不上传到互联网服务。
- 家属二维码只保存在设备的 `imgstore` 分区。
- 管理密码只保存随机盐和 SHA-256 摘要，不保存明文。
- 完整家庭住址默认不展示；主要联系电话可以选择脱敏显示。
- Wi-Fi 和本地网页只在设置时运行；应用正常使用时关闭蓝牙。

这仍是一张可能被别人看到的实体卡。不要填写身份证号、银行卡信息、门锁密码等高风险秘密。
本应用不是医疗器械，也不能替代急救服务或专业照护。

## 兼容性

此版本基于当前 `FoloToy/ai-passport` 模板，并保留小程序蓝牙安装契约：

- ESP32-C3、8 MB Flash、3 MB 主应用分区
- `cardid` 固定在 `0x356000`
- 永久 Recovery 固定在 `0x700000`
- 开机持续按住上键五秒进入 Recovery

NVS 命名空间、键名以及 `imgstore`、`imgframe` 地址与原版老人安心牌一致；只要分区内容仍在，
升级后可以继续使用原有资料和二维码。

## 构建与安装

使用 ESP-IDF 5.5.3：

```bash
source /path/to/esp-idf/export.sh
./tools/validate.sh
```

发布和安装时只使用 `build/FoloToy-AI-Passport-full.bin`。已经写入设备身份的机器，优先通过
AI Passport 小程序的 Recovery 流程安装。不要执行 `erase-flash`，否则会清除设备身份和永久 Recovery。

构建通过不等于真机验证。正式发布前，应在实体设备上检查首次设置、五个资料页、二维码扫码、
管理密码、一分钟休眠、按键唤醒和 Recovery 入口。
