# Tamagezi concept assets

`pet-roster-v1.png` is a visual direction sheet, not a production spritesheet.

The 4 × 3 cells map to the roster in reading order:

1. SPRIG
2. EMBER
3. BLOOP
4. ROOK
5. NIMBUS
6. COGGO
7. NOVA
8. INKY
9. HONEY
10. TEMPO
11. LUNA
12. ZIP

The concept sheet was generated with the built-in image generation tool from an original prompt. It intentionally contains no Tamagotchi characters, logos, UI, or copied franchise assets. Production sprites must be redrawn on a 48 × 48 pixel grid with the palette and animation constraints in `docs/TAMAGEZI_GAME_AND_CHARACTER_DESIGN.md`.
