# FoloToy AI Passport — Projects

This fork of [`FoloToy/ai-passport`](https://github.com/FoloToy/ai-passport)
develops independent applications on the AI Passport wearable (ESP32-C3, 8 MB
Flash, no PSRAM). Each project lives on its own `feature/*` branch, and this page
presents the **full content of each project** — what it does and how to use it —
so the collection is discoverable from the repository's landing page. The board
baseline, hardware, BSP, and contribution rules come from the upstream
repository.

## Projects

### Voice Keychain

A sound-effects keychain that turns the AI Passport into a pocket audio player.
Open it and instantly play one of hundreds of Chinese voice clips from dozens of
character packs — jojo, meme cat, Liu Huaqiang, Haji Mi, Nailong, Xiao Ming
Jian Mo, and more.

**What it does**

- **Character directory**: browse all character packs as a scrollable list; each
  entry is a pack of voice clips (e.g. jojo, MC, meme cat, Liu Huaqiang,
  Liu Haizhu, Kaqiu Mixue'er, Luyin, Indian A-san, Ji Yi Kawai, Haji Mi,
  Nailong, Bao Bao Duda Leilei, Xiao TuanTuan, Xiao Ming Jian Mo).
- **Clip list**: enter a pack to see its clips by name.
- **One-tap playback**: press OK to play the selected clip; built-in decoding
  plays 8 kHz mono IMA-ADPCM audio.
- **Settings** (hold OK): show the current battery percentage and voltage, and
  adjust the playback volume.

**Interaction**

Three keys drive the whole app. A top bar shows the title and, on the home
screen, the battery percentage (e.g. `97%`).

- **UP / DOWN** — move selection (hold to scroll).
- **OK** — enter a directory / select a clip / play.
- **OK (hold)** — open settings, or go back.

Long entries scroll horizontally so the full name is readable; the selected row
is highlighted in blue. The clips live in a `voicefs` SPIFFS data partition
(mounted at `/voices`), built via `tools/encode_voice.py` (decode → resample to
8 kHz mono → IMA-ADPCM 4-bit → `main/voice_index.h` + `voicefs.img`), and the app
flashes the merged firmware image and that data partition separately.

- Branch: [`feature/voice-keychain`](https://github.com/Shinku-Chen/ai-passport/tree/feature/voice-keychain)
- Archive: [`plays/shinku-chen/voice-keychain/`](plays/shinku-chen/voice-keychain/README.md)

### What to Eat Today

A food-roulette decision helper. Not sure what to eat? Hold the buttons to spin
through a food lottery and release to land on a random food.

**Interaction**

Three keys drive the app (button callbacks run in the button task, so they stay
non-blocking; the animation loop runs on an LVGL timer):

- **Hold UP** — play the guide animation ("what should we eat for lunch?").
- **Hold DOWN** — spin through the food-selector animation.
- **Release** — stop on the current frame (the food you landed on).
- **OK (hold)** — return to the menu (intercepted by `main.c`).

The "release" is detected by polling `bsp_button_read_mv()` (this BSP has no
RELEASE event): released ≈ 3300 mV, pressed < 2000 mV.

**What it does**

- A top-right battery indicator (read from `bsp_battery_soc()`) shows the live
  charge, degrading gracefully when the reading is `-1`.
- Auto-poweroff after a period of idle.
- No PSRAM needed: the food frames are embedded as LVGL `LV_COLOR_FORMAT_I8`
  index-color binary (via CMake `EMBED_FILES`), so the animation runs from Flash
  without a frame buffer.

The frames come from `main/eat_what_g1.bin` / `main/eat_what_g2.bin` (256-color
palette + pixel index per frame, generated by
`tools/generate_eat_what_assets.py`). Cover art is
`assets/images/eat-what-cover.png` (2048 × 2048): "a cute cartoon TV showing
burgers, ramen, dumplings, hotpot, and milk tea."

- Branch: [`feature/cheerful-goodall`](https://github.com/Shinku-Chen/ai-passport/tree/feature/cheerful-goodall)
- Entry: `main/demo_eat_what.c`

### Shengzi Cards

A Chinese-character flashcard memorization app. The firmware boots straight into
this application using the `ui_pixel` theme (sky background, grass, title plate,
mascot, ink-outlined panels) on the 240 × 320 display.

**Three modes**, switched by holding **UP / DOWN**:

- **Browse** — scroll through the character cards (a large character card with
  its pinyin above and a hint line below).
- **Self-test** — mark each character as learned / not learned.
- **Spell** — see the pinyin and guess the character.

A short **OK** press reveals the answer in the self-test / spell modes. The
"learned" marks persist to NVS (`sz_data`), so progress survives a reboot. The
screen layout is a title bar (≈ y0–46), a pinyin row (y ≈ 58), the large
character-card region (y ≈ 78–218), and a bottom info line (y ≈ 255–290).

- Branch: [`feature/shengzi-cards`](https://github.com/Shinku-Chen/ai-passport/tree/feature/shengzi-cards)
- Entry: `main/demo_shengzi.c`
